## Мобильная клиентская часть платформы для квиз-игр
Серверная часть: https://github.com/roman23323/quiz-server

Данное приложение реализовано на языке TypeScript с использованием фреймворков React Native и Expo.
Для HTTP-запросов используется axios, а для WebSocket - Socket.io-client.

Здесь реализованы несколько экранов: регистрация, логин, список квизов, создание, генерация квизов, экран с вопросом и результаты прохождения
